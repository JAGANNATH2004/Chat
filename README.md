# Simple Bidirectional Chat

A simple, lightweight real-time chat application with a clean white interface and instant bidirectional messaging across devices.

## How to Run & Use

### 1. Start the Server
```bash
python main.py
```

### 2. Open on Both Devices
- **On this computer**: Open [http://localhost:8000](http://localhost:8000)
- **On your phone / other device**: Open `http://<your-computer-ip>:8000` (e.g. `http://192.168.1.24:8000`) in Chrome / Safari on the same Wi-Fi.

Type a message on either device and press **Send** — it will immediately appear on the other device!
